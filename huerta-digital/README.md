# Huerta Digital V05.1 — Edición final de feria

Grupo 8 del 1.º BTI, Colegio Nacional de Villarrica, Feria de Informática 2026.

**Equipo:** Ángela, Reinaldo y Tiara. Los nombres aparecen sin asignación de funciones individuales no confirmadas.

Incluye 7 páginas: Inicio, Cultivos, Siembra, Trivia, Decisiones, Participá y Fuentes.

La V05.1 conserva intactas las siete fotografías originales y los cuatro archivos JavaScript funcionales de la V05. Se añadieron solo contenido editorial, una infografía original en SVG, crédito grupal y mejor organización.

Abrir `index.html` o desplegar el contenido de esta carpeta en `huerta-digital/` de GitHub Pages.

Las fuentes de información agrícola se encuentran en `fuentes.html`. Las autorizaciones de las siete fotografías no están documentadas en el paquete original; no se les asignó una licencia inventada. El docente debe conservar las autorizaciones pertinentes para su difusión pública.
