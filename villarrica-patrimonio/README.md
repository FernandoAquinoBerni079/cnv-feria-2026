# Villarrica: Historia y Patrimonio — Feria de Informática 2026
Proyecto estudiantil de Teili, Iara y Alexander, 1.º BTI del Colegio Nacional de Villarrica.

## Uso
Abrir `index.html` en el navegador o publicar los archivos en una carpeta de GitHub Pages.

## Archivos
- index.html: portada y fichas originales.
- cronologia.html: seis hitos históricos y formulario demostrativo.
- lugares.html: nuevas fichas educativas.
- galeria.html: galería de fotografías originales con filtros y visor.
- juegos.html: trivia de 10 preguntas.
- fuentes.html: fuentes complementarias y atribuciones.

La V07.2 conserva las ocho imágenes originales. Consulte INFORME_CAMBIOS_V07_2.md para detalles y consideraciones sobre permisos de imágenes.
